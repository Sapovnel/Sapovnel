### Featured project

<a href="https://github.com/Sapovnel/coinscope">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Sapovnel&repo=coinscope&theme=tokyonight&hide_border=true&bg_color=0d1117" />
</a>

**[Coinscope](https://github.com/Sapovnel/coinscope)** — Real-time crypto market tracker built as a single-page React app. Pulls live data from the CoinGecko API to power a price dashboard, a custom-built squarified treemap heatmap colored by 24h change, multi-coin comparison charts, a dollar-cost-averaging backtesting simulator, a portfolio P&L tracker, and a price-alert system with browser notifications. Shipped as an installable PWA with offline-capable service worker. All charts hand-rolled in SVG (no chart library).

**Live demo:** https://sapov-coinscope.hf.space

`React` · `Tailwind CSS` · `CoinGecko API` · `Custom SVG visualization` · `PWA` · `Service Workers`
